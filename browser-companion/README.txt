Nibble Recipe Companion (Production 1.0.1; Chrome / Edge)

1. Extract this folder if it came in a ZIP.
2. Open chrome://extensions or edge://extensions in your browser.
3. Turn on Developer mode, click Load unpacked, and select this folder
   (the one containing manifest.json). Keep the folder after installation.
4. Open a recipe website normally. If the site asks for a human check,
   complete it yourself in the browser before using the companion.
5. Click the Nibble companion, then Read this recipe. Review the captured
   content and selected food photo, then click Save recipe file.
   The photo is embedded in the JSON; importing it in Nibble stays offline.
   If the photo cannot be read, copy the food image and paste it in Nibble:
   Change cover photo > Ctrl+V > Use this photo > Save recipe.
6. In Nibble: Import Recipe > Import from browser > Choose saved recipe.
   Choose the .nibble-recipe.json file, then Create recipe draft.
7. Review every ingredient, quantity, instruction, and serving field.

No paid service, account, API key, or local server is needed.
Only activeTab and scripting permissions are requested. No automatic
background requests, cookie access, browsing history, telemetry, or remote uploads.
After you click Read, the companion may fetch a same-site image without cookies
or redirects. Protected cross-site image pixels cannot always be read.
See privacy.html for storage details and the import policy.

This does not unlock content your browser cannot access. If a recipe is
an image, video, or unsupported page layout, use Nibble's screenshot or
text import instead. This first version is distributed locally, not
through a browser extension store.
